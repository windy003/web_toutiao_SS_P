Agent”：不是一个插件、也不是助手，而是一个具备自主探索、任务执行和反馈能力的 AI 工具链，通过循环运行模型完成任务。<br>Claude Code 的工作方式：不是记住一切，而是像人一样探索<br>传统做法通常会构建一个巨大的 embedding 向量库、配置 RAG 检索系统，再加一堆索引逻辑。<br>而 Claude Code 完全绕开了这些繁杂步骤。<br>它选择了“agentic search”的方式——像一个新加入团队的程序员那样，使用 grep、glob、find 等命令主动去探索代码，而不是坐等代码“被喂到”眼前。<br>从 Claude 的视角来看，项目目录并不是一个静态知识库，而是一个可动态交互的环境。<br>Claude 会在探索中逐步构建任务视图，并根据结果继续迭代。这种机制让 Claude Code 更轻、更快、也更像“人”。<br>此外，它还有一整套工具链：可以执行终端命令、读写文件、连接外部 MCP Server 拉资源。更重要的是，它的行为全部可控——所有“写文件”或“执行脚本”的操作，都会经过权限确认，最大限度保障安全性。<br>claude.md：Agent 记忆的关键载体<br>Claude Code 没有记忆，但你可以通过 claude.md 文件“教会”它你的项目和习惯。<br>这个文件是 Claude 启动时自动注入 prompt 的上下文源。<br>你可以写进项目结构说明、单测运行方式、常用命令、开发规范等信息。把它放在根目录、提交进 Git 仓库，Claude 在任意终端启动时都能读取这份“共识”。<br>还可以用 @ 引用其他文档，实现多级上下文扩展。每个子目录也能拥有自己的 claude.md，让复杂项目或 monorepo 拥有精细的上下文管理。<br>不仅如此，这个机制还能让多个 Claude 实例“共享记忆”——例如 Agent A 写入 ticket.md，Agent B 再读取继续工作，构建一个手动版本的“多 Agent 协作”体系。<br>Claude Code 不只是写代码：它在整个开发周期都有用武之地<br>从熟悉新项目、理解遗留系统，到设计功能、探索实现方案、生成单测、编写文档，再到 CI/CD、部署、调试、自动提交 PR，Claude Code 几乎覆盖了开发生命周期的所有阶段。<br>比如你可以对它说：“Claude，帮我看一下这个 bug 可能的原因，再规划一个修复方案。”它不会直接改代码，而是先搜索、分析、列方案，等你确认再动手。这种方式不仅更安全，也更透明。<br>而在版本控制中，Claude Code 还能自动生成 commit message 和 PR 描述。调试阶段更可贴图调试、多模态支持全面拉满。甚至你不熟悉 Git、Docker、BigQuery？也可以直接让 Claude 接管终端操作。<br>多个 Claude 并行协作？是时候尝试 Agent 编排了<br>在这次分享中，Cal 也透露了一个颇具未来感的用法：多个 Claude 实例并行协作。<br>你可以开多个终端标签页，运行多个任务，比如一个分析 bug、一个写测试、一个构建文档。<br>甚至还能在 Tmux 中进行 Agent 编排。虽然目前上下文不能原生共享，但结合 claude.md 和中转 markdown 文件，也可以构建出“类多智能体”的协作环境。<br>别忘了，还有 /compact 命令。<br>当上下文快满时，它会触发一次总结与“交接”，就像开发任务临时交班一样。Claude 会生成一个当前会话的高质量摘要，新任务以此为基础继续运行，让工作不断档。<br>进阶玩家必修技巧：自动执行、无头集成、think hard 模式<br>Claude Code 也逐步支持更多 DevOps 场景，包括 GitHub Actions 的集成、headless 自动调用等场景。<br>你可以让 Claude 在没有 UI 的环境下自动运行任务，处理大型迁移、自动测试、CI/CD 检查等批量任务。<br>同时，Claude 新增的 “think between tool calls” 功能，也让任务执行过程中能插入更深度的思考。<br>只要输入  think hard  ，Claude 就会在下一次工具调用前展开分析。特别适合处理复杂决策任务，比如兼容性改造、架构重构等高风险场景。<br>最后，还有 IDE 插件也同步更新。<br>现在 Claude Code 已深度集成 VS Code 和 JetBrains 系列，能自动识别你当前编辑的文件，并联动上下文完成交互。这让你不再需要手动 copy 文件、手动提示，整个开发体验更加自然顺滑。<br>对于 AI 编程工具的发展来说，Claude Code 的方法论无疑是一次重要突破——不是在工具栏加个 AI，不是“生成代码粘贴到 IDE”，而是真正将模型运行逻辑嵌入到开发流程中，成为一个能够持续工作、主动探索、实时反馈的智能开发搭档。<br>而这次分享，也是 Claude Code 首次正式对外揭示其设计哲学与内部工作方式。未来，它或许不仅是一个智能编程助手，更可能是开发团队中真正的一员，一个拥有探索力、判断力和执行力的 AI 工程师。<br>Anthropic 的这个“开源级自曝”，或许才是 Claude Code 真正的起点。
